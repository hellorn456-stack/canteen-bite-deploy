Place your college logo file here as: logo.png
(or any format: .jpg, .svg, .webp)

Then update the import in LoginScreen.jsx:
  import logoUrl from '../assets/logo.png';

If you have a .svg logo, use:
  import logoUrl from '../assets/logo.svg';

The logo will appear on the login screen header.
Recommended size: 200x200px or square format.
